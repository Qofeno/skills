✓ STABLE 01 / BACKEND

backend-setup-wizard

Provisions, configures, and deploys live backends and 3rd-party services (Supabase, Firebase, Stripe, Postgres, Resend, Vercel) through CLI without ever touching or leaking raw secrets in chat.

  • Zero-Knowledge Auth: Uses official OAuth / CLI login flows.

  • Production Deploy: Direct sync to Vercel, Fly.io, or Railway secret stores.

✓ STABLE 03 / SECURITY

security-hardening-wizard

Scans every single file in the workspace (code, configs, markdown, CI YAML, Dockerfiles, IaC) for vulnerabilities, applies real fixes directly to code, and hardens the live infrastructure.

  • Fixes, Not Suggestions: Remediates injection, auth, and CORS flaws.
  • Secret Leaks Defense: Gitleaks git-history scan & .env isolation.
  • Verified Audit: Generates a verified markdown security compliance report.

✓ STABLE 04 / ORCHESTRATION

skill-router

Pre-flight orchestrator that inspects all installed skills across any publisher before starting substantive work. Prevents skills from being missed when user prompts use informal wording.

  • Universal Compatibility: Checks skills from any vendor or repository.
  • Semantic Matching: Matches intent rather than exact trigger words.
  • Zero Overhead: Fast frontmatter scan before coding begins.

Why we refuse to fake it

Traditional AI coding assistants often take the path of least resistance by generating stubs. Qofeno skills enforce strict production execution.

Task Domain Ordinary Agent Behavior Qofeno Skills Standard
Backend Setup Writes YOUR_API_KEY_HERE in .env and outputs mock JSON data. Authenticates via OAuth CLI, generates real tables, and validates live endpoints.
UI & Web Design Dumps Lorem Ipsum, generic grey placeholder boxes, and single desktop mocks. Builds complete responsive pages, custom font pairings, and captures real running UI.

# Add to AGENTS.md, CLAUDE.md, or .cursorrules:

## Autonomous Skill Routing Rule
Before starting any substantive coding task, list all installed skills in skills/ or .agents/skills/. Match the user intent against each skill's frontmatter and execute the matched wizard workflow. Never bypass a matching skill.
